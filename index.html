Decoder-Only Transformer

8-layer autoregressive model with tied embeddings, trained on 1.83M presentations

Input Tokens
x x y⁻¹ y⁻¹ y⁻¹ SEP x⁻¹ y EOS
↓
Token Embedding + Positional
W_E(token) + P(position) → ℝ⁵¹²
↓
8 × Transformer Block
LayerNorm → Causal Self-Attention (4 heads, head_dim=128) → Residual
LayerNorm → MLP (512→2048→512, GELU) → Residual
↓
Final LayerNorm → Unembedding (tied: W_U = W_E^T)
Hidden state h ∈ ℝ⁵¹² → Logits ∈ ℝ⁶
↓
Language Model Loss
Next-token prediction (cross-entropy)
EOS Embedding → ℝ⁵¹²
Used for t-SNE + Hardness Oracle H(P)

Training

  • AdamW optimizer (β₁=0.9, β₂=0.95)
  • Weight decay: 0.1
  • BF16 mixed precision on CUDA
  • Sequence packing (no padding waste)
  • Linear warmup → cosine decay
  • Validation loss target: ~0.7337

Hardness Oracle H(P)

  • Input: 512-dim EOS embedding
  • Architecture: Linear(512→128) → ReLU → Linear(128→1)
  • Output: P(GS-solved)
  • 5-fold stratified CV
  • Target F1 ≥ 0.962
  • Paper baseline: XGBoost F1 = 0.962

Key Insight (Section 6.3)

"There likely exists an invariant at the level of the 'language' of the balanced presentations that distinguishes GS-solved vs GS-unsolved presentations."

The trained transformer's EOS embeddings naturally cluster GS-solved vs GS-unsolved in t-SNE space — revealing structure invisible to the raw int8 representation.
